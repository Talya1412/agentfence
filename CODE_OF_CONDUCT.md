# Code of Conduct

Contributors must keep collaboration respectful, specific, and safe.

Expected behavior:

- Discuss code, documentation, and evidence without personal attacks.
- Welcome corrections and distinguish current behavior from future ideas.
- Protect secrets, private reports, and personal data.
- Follow maintainer instructions during security response.

Unacceptable behavior includes harassment, threats, discrimination, doxxing, deliberate secret disclosure, and knowingly misleading security or compatibility claims.

Report conduct concerns privately to repository maintainers. Security issues belong in the private process described in [SECURITY.md](SECURITY.md).
