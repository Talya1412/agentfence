# Support

Use GitHub Issues for reproducible bugs, compatibility reports, and focused feature requests. Include:

- AgentFence version from `agentfence version`.
- OS and architecture.
- Downstream server command and version.
- Minimal JSONL input, with secrets removed.
- Config shape, with credentials and private paths removed.
- Expected and observed output.

Use Discussions for setup questions and design discussion when enabled by repository maintainers. Do not post credentials, audit files, private tool arguments, or exploit details in public issues. Report security vulnerabilities through GitHub's private vulnerability reporting channel when available; otherwise follow [SECURITY.md](SECURITY.md).
